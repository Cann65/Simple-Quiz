# Simple Quiz

A browser quiz built with HTML, CSS, and vanilla JavaScript. Question data and short audio cues are included in the repository.

Run it from the repository root with Python 3:

```bash
python -m http.server 8009 --bind 127.0.0.1
```

Open http://127.0.0.1:8009/. The local HTTP server makes the question files available to the browser's fetch API.
